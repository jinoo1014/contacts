# 공공기관 연락처 찾기

4대보험 3개 공단과 전국 세무관서의 **부서별 직통 연락처**, 그리고 전국 지방자치단체 **누리집 바로가기**를 한 화면에서 찾는다.

- **25,938건** · 기준일 2026-08-18
- 지사명·부서명·담당업무 아무거나 넣으면 된다. 초성(`ㄱㅁㄱㄱㅂㅎ`)도 된다.
- 기관 → 지역본부 → 지사 → 부서 4단계로 좁힐 수 있다.
- 여러 단어는 모두 포함, `-단어` 는 제외.
- 줄 끝의 🏛 을 누르면 그 기관 공식 누리집이 새 창으로 열린다.
- 제목이나 로고를 누르면 처음 화면으로 돌아온다.

## 지자체는 왜 번호가 없나

2026-08-18 확인한 결과, 지자체 세무과 직통번호를 전국 단위로 모을 방법이 없다.

| 경로 | 결과 |
|---|---|
| 위택스 | robots.txt 가 `Disallow: /` 로 전체 차단 |
| 공공데이터포털 | 서울 25 + 경기 31 중 부서 연락처 자료가 실질 4곳. 내려받기에 캡차 제한 |
| 서울열린데이터광장 | '부서 전화번호' 검색 결과 17건 |
| 각 지자체 누리집 직접 | 서울·경기 56곳 중 전면차단 20 · 조직도차단 4 · 접속실패 6 · 열림 26 |

반쪽짜리 번호를 넣으면 "안 나오는 게 없어서인지 안 모아서인지" 알 수 없다.
그래서 번호 대신 **누리집 바로가기**만 싣는다. 정부24의 기관 누리집 목록에서 받았고,
robots.txt 가 그 경로(`/portal/orgSite*`)를 이름 대어 열어 두었다.

## 배포 방법

같은 폴더의 **`깃허브배포방법_260818.txt`** 에 브라우저로 끌어다 올리는 방법을 처음부터 끝까지 적어 두었다.
명령어를 칠 일이 없다. 명령어 방식은 그 문서 부록에 있다.

무료 계정은 **저장소가 공개여야** Pages 가 동작한다. 비공개로 둘 거면 HTML 파일만 나눠 주면 된다.

없는 링크를 있는 척하지 않는다.

## 데이터를 새로 뽑을 때

상위 폴더에 원본 CSV(`raw/`)와 수집 스크립트(`tools/`)가 있다.

```bash
python tools/lgov.py -o raw/지방자치단체_누리집_<YYMMDD>.csv --asof <날짜>
python tools/convert.py raw/*.csv raw/*.CSV -o data.json --asof <날짜>
python tools/verify.py data.json
python tools/bundle.py -o web/index.html
python tools/bundle.py -o web/연락처찾기_<YYMMDD>.html
```

`bundle.py` 는 열별 사전으로 줄여 넣는다(10.8MB → 3.6MB, 33%). 줄이지 않으려면 `--plain`.
`web/logo.*` 가 있으면 그림도 통째로 안에 넣는다.
