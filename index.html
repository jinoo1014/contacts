검색 도움말

기본

  • 전화번호는 하이픈을 넣든 빼든 같습니다. 061-430-4615 = 0614304615 = 061-430
  • 글자는 단어 그대로 찾습니다. 수서를 치면 수서가 들어간 줄만 나옵니다.
  • 여러 단어를 쓰면 모두 포함된 줄만 나옵니다. 예) 완도 요양
  • -단어는 제외합니다. 예) 건강보험 -지사장
  • "따옴표"로 묶으면 그 표현 그대로 찾습니다.

초성 검색

  • 초성만 입력해도 됩니다. ㄱㅁㄱㄱㅂㅎ → 국민건강보험
  • 초성과 단어를 따로 띄어 섞어도 됩니다. 예) ㅇㄷ 요양
  • 한 단어 안에 글자가 섞여 있으면 초성으로는 찾지 않습니다. 마포세무서를 쳤을 때 ㅁㅍㅅㅁㅅ인 다른 줄이 딸려 나오지 않게 하려는 것입니다.

결과 내 검색

  • 검색 결과 위의 결과 내 검색 칸에 넣고 엔터를 치면 조건이 하나 쌓입니다. 여러 번 겹칠 수 있습니다.
  • 조건 옆 ✕를 누르면 그 조건만 풀리고 나머지는 그대로 남습니다.
  • 여기서도 -단어와 "따옴표"를 쓸 수 있습니다.
  • Esc 또는 전체 초기화를 누르면 조건이 전부 사라집니다.

못 찾았을 때 (자동으로 두 번 더 찾습니다)

  • 띄어쓰기 무시 — 강진완도 → 데이터에 강진 완도지사로 있어도 찾습니다.
  • 오타 보정 — 국민건간보험 → 국민건강보험을 찾습니다.
  • 이렇게 찾은 결과는 건수 옆에 그렇다고 적힙니다.

데이터 바꾸기

  • 엑셀·CSV 파일을 화면에 끌어다 놓으면 바로 반영됩니다(이 브라우저에서만).
  • 모두에게 반영하려면 저장소의 data.json을 교체하세요.
