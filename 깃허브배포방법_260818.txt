2-2. 화면 가운데쯤에 이런 문장이 있습니다.

     이 파란 글씨를 누릅니다.

     안 보이면 (파일이 이미 있는 저장소면) 위쪽의

     안의 파일들을 전부 선택해서(Ctrl+A) 브라우저 화면 위로 끌어다 놓습니다.

  * 폴더째 끌어도 됩니다. 다만 web 폴더째 끌면 저장소 안에 web 폴더가 생겨서
    5번의 Pages 폴더 설정을 /web 으로 맞춰야 합니다. 헷갈리니

     중간에 창을 닫으면 처음부터 다시 해야 합니다.

2-5. 화면 아래 "Commit changes" 칸이 있습니다.

        Commit changes 칸에 :  공공기관 연락처 찾기 25,938건
        아래 두 개 중에는    :  Commit directly to the main branch  (기본값)

     초록색 [ Commit changes ] 를 누릅니다.

끝났습니다. 파일 목록에 방금 올린 것들이 보입니다.

4-1. 점(.)으로 시작하는 파일이 안 보인다

     탐색기 위쪽  보기 -> 표시 -> 숨긴 항목  을 켜면 보입니다.

4-2. .nojekyll 이 안 올라간다

     0 바이트 파일이라 브라우저 업로드가 그냥 무시하기도 합니다.
     이 앱에는 사실 없어도 됩니다. 밑줄(_)로 시작하는 파일이 없어서
     깃허브가 건너뛸 게 없습니다. 없으면 없는 대로 두셔도 됩니다.

     그래도 넣고 싶으면 저장소에서 직접 만들면 됩니다.
        [ Add file ▼ ] -> Create new file
        -> 파일 이름 칸에  .nojekyll  입력
        -> 내용은 비워 둔 채 [ Commit changes ]

4-3. 한글 파일 이름

 10. 잘 안 될 때
--------------------------------------------------------------------------------

Q. 업로드가 자꾸 멈춘다
   -> 파일을 한 번에 다 올리지 말고 두세 개씩 나눠 올려 보세요.
      Upload files 는 여러 번 해도 됩니다.

Q. "Yowza, that's a big file" 이라고 뜬다
   -> 파일 하나가 25MB 를 넘었다는 뜻입니다. 이 앱 파일은 다 그보다 작으니
      엉뚱한 파일을 끌어 놓지 않았는지 보세요.

Q. Pages 주소가 404
   -> 5-3 에서 폴더가 / (root) 인지 봅니다. index.html 이 저장소 맨 위에
      있어야 합니다. web 폴더 안에 들어가 있으면 /web 을 골라야 합니다.
   -> 배포에 몇 분 걸립니다. Actions 탭에 초록 체크가 떴는지 확인합니다.

Q. 화면은 뜨는데 "샘플 데이터" 라는 노란 띠가 있다
   -> index.html 이 데이터 없는 옛 파일입니다.
      C:\연락처수집\web\index.html 을 다시 올리세요.

Q. 로고가 안 보인다
   -> Ctrl+F5 로 강력 새로고침을 해 보세요.
      그래도 안 되면 로고가 앱에 안 박힌 것이니 알려 주세요.

Q. 첫 화면이 느리다
   -> 3.6MB 를 받아 25,938건을 펼치느라 그렇습니다. 처음 한 번만 그렇고
      다음부터는 브라우저가 기억해서 빠릅니다.

Q. 누리집 아이콘이 어떤 줄에는 없다
   -> 고장이 아닙니다. 그 지사 전용 페이지가 있는 줄에만 뜹니다.
      25,938건 중 19,797건(76%)입니다.
      근로복지공단과 국세청 본청은 기관 공용 검색화면뿐이라 안 뜹니다.
      대신 줄을 눌러 상세를 열면 검색화면 링크가 이름과 함께 나옵니다.

Q. 올린 걸 내리고 싶다
   -> Settings 맨 아래 Danger Zone -> Delete this repository.
      Pages 주소도 같이 죽습니다. 다만 검색엔진 캐시는 바로 안 사라집니다.
      공개만 끄고 싶으면 Change repository visibility 로 Private 로 바꿉니다.


--------------------------------------------------------------------------------
 부록. 명령어로 올리는 방법 (안 쓰셔도 됩니다)
--------------------------------------------------------------------------------

브라우저 업로드가 번거로워지면(파일이 많아지면) 이 방법이 편합니다.
한 번 설정해 두면 다음부터는 세 줄이면 끝납니다.

  처음 한 번만
    cd C:\연락처수집\web
    git init
    git add .
    git commit -m "공공기관 연락처 찾기 25,938건"
    git branch -M main
    git remote add origin https://github.com/<내계정>/contacts.git
    git push -u origin main

  그다음부터
    cd C:\연락처수집\web
    git add .
    git commit -m "데이터 갱신"
    git push

  * push 할 때 로그인 창이 뜹니다. "Sign in with your browser" 를 누르면
    브라우저로 넘어가 로그인하면 됩니다.
  * 이미 브라우저로 파일을 올려 뒀다면 처음 한 번에서 push 가 거부됩니다.
    이렇게 합치면 됩니다.
        git pull origin main --allow-unrelated-histories
